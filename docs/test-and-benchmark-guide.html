Test & Benchmark Guide

Node.js Microservices — notification-service, task-service, user-service

1. Unit Tests

Unit tests validate individual controllers, services, utils, and middleware in isolation using mocks.

Run All Services

npm run test

Run Individually

npm run test:task          # task-service
npm run test:user          # user-service
npm run test:notification  # notification-service

What Gets Tested

Tip: Use jest --verbose to see individual test names. Add --watch for watch mode during development.

2. Coverage Reports (HTML)

Generates HTML coverage reports at 90% threshold across branches, functions, lines, and statements.

Run Coverage — All Services

npm run test:coverage --workspaces

Run Coverage — Per Service

npm run test:coverage --workspace=task-service
npm run test:coverage --workspace=user-service
npm run test:coverage --workspace=notification-service

Report Locations

ServiceHTML Report
notification-servicenotification-service/coverage/index.html
task-servicetask-service/coverage/index.html
user-serviceuser-service/coverage/index.html
Combined (all services)coverage/index.html
Coverage thresholds are enforced in each service's jest.config.js: branches ≥ 90%, functions ≥ 90%, lines ≥ 90%, statements ≥ 90%.

3. Integration Tests

Integration tests run against real MongoDB and RabbitMQ instances.

Prerequisites

docker compose up -d

Run

npm run test:integration --workspace=task-service
npm run test:integration --workspace=user-service
⚠ Note: Integration tests are currently disabled (describe.skip) because MongoMemoryServer requires downloading a ~600MB MongoDB binary which times out. To enable: remove the skip and ensure a cached MongoDB binary or a local MongoDB instance is available.

4. Benchmark (HTTP Throughput & Latency)

Measures raw HTTP performance using autocannon against mock servers (no real DB). Results reflect the Node.js HTTP layer capacity.

Tool: autocannon

PropertyDetail
Nameautocannon
AuthorMatteo Collina
PurposeFast HTTP/HTTPS benchmarking for Node.js
Key FeaturesHigh-performance via http.request, supports pipelining, connections, duration config, latency percentiles (p50, p99), throughput metrics, JSON output
Installnpm install -g autocannon

Run

npm run benchmark

Configuration

Edit benchmark/config.js to adjust:

ParameterDefaultDescription
connections100Concurrent TCP connections
pipelining10Requests pipelined per connection
duration5sBenchmark duration per endpoint
timeout30000msGlobal timeout
